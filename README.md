# 🎮 Rock, Paper, Scissors

A simple command-line Rock, Paper, Scissors game in pure Python.
Every round is saved to a separate `history.txt` file (CSV format).

![Python](https://img.shields.io/badge/Python-3.7%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Features

- 🪨📄✂️ Classic Rock, Paper, Scissors
- 🗄️ Separate `history.txt` for every round
- 📜 View history from the menu
- 📊 Live score (wins / losses / ties)
- 🧹 Clear history option
- 🐍 No external dependencies

---

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
